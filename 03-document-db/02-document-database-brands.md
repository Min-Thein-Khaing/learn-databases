# 3.2 Document Database Brands

Document database products share the same basic idea, but they differ in
how they are hosted, queried, scaled, and priced.

| Brand | Best known for |
|---|---|
| **MongoDB** | General-purpose document database with a large ecosystem and a managed cloud service called Atlas |
| **Amazon DocumentDB** | AWS-managed document database designed for compatibility with MongoDB workloads |
| **Amazon DynamoDB** | Serverless, fully managed, distributed key-value and document database with single-digit millisecond performance at any scale |
| **Azure Cosmos DB** | Globally distributed cloud database that supports a document data model and multiple APIs |
| **Google Cloud Firestore** | Serverless document database commonly used by web and mobile applications |
| **Couchbase** | Distributed JSON document database with caching, search, and mobile features |
| **Apache CouchDB** | Open-source document database known for HTTP access and replication |

## Which one will this course use?

This course uses **MongoDB** because it can run locally, in Docker, or in the
cloud, and its document model is easy to explore with practical examples.
The document database ideas in the first lessons are broader than MongoDB.

## A note about names

**Amazon DocumentDB** is the name of one AWS product. Lowercase
**document database** is the general database category. They do not mean the
same thing.

## Recap

- MongoDB is one document database brand, not the definition of the category.
- Cloud providers offer managed document database services.
- Products differ even when they store similarly shaped documents.
- The rest of this module uses MongoDB for hands-on practice.
